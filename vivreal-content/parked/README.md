# Parked (owners, 2026-10-28, D8)
Claude Code loads a plugin's components from their default locations (`agents/`, `commands/`, `skills/`, `hooks/hooks.json`, `.mcp.json` and the rest of the Standard layout table in the plugins reference, https://code.claude.com/docs/en/plugins-reference#standard-layout) or from paths `plugin.json` names. `parked/` is neither, and this plugin's `plugin.json` names no component paths, so nothing here can be dispatched or run. If a component key such as `agents` or `commands` is ever added to `plugin.json`, check it does not reach into `parked/`. These were parked because the 2026-10-26 cadence allows video only from the existing help tutorials, which tutorial-maker owns. To restore one: `git mv` it back, bump the plugin version, and add its route to `vivreal-workflow/routing/routes.json`.
