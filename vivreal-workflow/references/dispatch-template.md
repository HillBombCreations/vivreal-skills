# Dispatch template

From the owner-approved 2026-10-06 template plus audit-3 2.7. Every dispatch carries all eight.

Every dispatch: (1) ONE repository per coder or portal-coder dispatch; several repos means several dispatches. (2) The base or head SHA, pinned (`origin/main@<sha>`). (3) The spec file path when one exists. (4) The mode, for portal-coder. (5) The exact commands it may run and the test scope. (6) Full scope and authority in the first prompt; a GO is quoted verbatim with name, time and source. (7) Verified premises only: read the deployed validator or release line, not main. (8) Report at most 250 words, ending with any `Needs:` line.
